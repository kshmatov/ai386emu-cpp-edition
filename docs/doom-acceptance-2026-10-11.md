# Проверка Doom 1.9 Shareware

> История Go-издания: упоминания Go-команд, путей и цифр ниже относятся к Go-реализации (ai386).

Дата: 2026-10-11. Эмулятор из ветки `feature/freedos-doom`, FreeDOS 1.4 BASE,
16 МиБ RAM, виртуальная частота 1 МГц. Проверки выполнены через `Machine.Step`
и ввод PS/2; кадры получены через `Display.Frame`. Оконный фронтенд и слышимое
воспроизведение на устройстве хоста в этот прогон не входят.

Использована отдельная копия `build/freedos/freedos-ready.img`:
`/tmp/ai386-doom-test.img`. Исходный готовый образ не изменён.

## Результаты

| Проверка | Результат |
| --- | --- |
| Стандартный режим 2, JEMMEX, `DOOM -NOSOUND` | Запуск, DPMI и чтение WAD проходят. После исправления VGA игровой цикл остаётся в ожидании времени; меню не открывается. Повторные снимки показывают неизменный игровой счётчик времени. |
| Режим 4, HIMEMX/Safe Mode, `DOOM -NOMUSIC -WARP 1 1` | Уровень E1M1 и HUD отрисованы в 320×200. |
| Режим 4, `DOOM -NOMUSIC -TIMEDEMO DEMO1` | Демозапись воспроизводится: последовательные снимки показывают перемещение камеры и изменение сцены. Завершение всей демозаписи и FPS не проверены. |
| Клавиатура в режиме 4 | Esc не открывает меню. PIC: маска `FE`, IRQ1 запрещён, запрос остаётся в IRR (`02`). Управление не принято. |
| Sound Blaster, режим 4, демозапись | DMA работает, маска PIC меняется на `DE` с разрешённым IRQ5. Файловый backend записал 5 074 818 байт, все `80h` — тишина unsigned 8-bit PCM. Звуковые эффекты не подтверждены; наличие PCM само по себе не считается успешной проверкой звука. |

Для звукового прогона на тестовой копии задан `C:\DOOM\DEFAULT.CFG`:

```text
snd_sfxdevice 3
snd_musicdevice 0
snd_sbport 544
snd_sbirq 5
snd_sbdma 1
```

Sound Blaster подключён на 220h, IRQ5, DMA1/5; backend `file`.
Музыка отключена, поскольку OPL/MIDI пока не реализованы.

## Исправление, найденное тестом

Первый запуск зависал в цикле чтения `3DAh` по адресу `471C81h`:
VGA всегда возвращала ноль. Бит 3 Input Status 1 обозначает вертикальный
обратный ход ([FreeVGA, External Registers](https://web.stanford.edu/class/cs140/projects/pintos/specs/freevga/vga/extreg.htm)).

Сигнал теперь продвигается от виртуального времени независимо от IF,
частоты чтения порта и вызовов рендеринга. Используется приближённая
развёртка 70 Гц с интервалом обратного хода 1/64 кадра; точные тайминги
пикселей и программирование развёртки через CRTC не моделируются.

Регрессия `TestGuestCanWaitForVGARetraceWithInterruptsDisabled` исполняет
гостевой цикл ожидания трёх последовательных обратных ходов при CLI.
До исправления тест падал, после проходит. Дополнительный тест проверяет
стабильность повторных чтений, оба адреса порта и сброс flip-flop AC.

```sh
go test ./internal/vga ./internal/machine \
  -run 'TestRetraceStatus|TestGuestCanWaitForVGARetrace' -count=1
```

## Артефакты и повторение

Локальные снимки в игнорируемом каталоге `build/freedos/`:

- `doom-safe-game2.png` — E1M1;
- `doom-safe-menu.png` — результат нажатия Esc;
- `doom-sound-demo2.png`, `doom-demo-progress.png` — разные кадры демозаписи;
- `doom-test-audio.pcm` — сырой PCM звукового прогона.

Для ручного повторения запустите готовый образ:

```sh
go run -tags desktop ./cmd/ai386 --config=build/freedos/freedos-ready.toml
```

В меню FreeDOS выберите **4**. В приглашении DOS выполните:

```dos
CD \DOOM
DOOM -NOSOUND -WARP 1 1
```

Это повторяет проверку графики; обнаруженный сбой клавиатуры остаётся.
Для воспроизведения сбоя JEMMEX выберите **2** и запустите `DOOM -NOSOUND`.
Диагностическая консоль сохранена отдельно в `build/freedos/debug-install/`.

## Проверки проекта

`make check` прошёл: форматирование, `go vet`, unit-тесты, race-тесты,
сборка и OpenSpec (10/10). Linux desktop и обе Windows сборки прошли.
Проверка установщика с официальным ISO `TestFreeDOSInstallMenu` прошла
за 22,303 с. Полная совместимость Doom пока не принята: остаются JEMMEX,
клавиатура и проверка звуковых эффектов.
