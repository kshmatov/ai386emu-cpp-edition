# Самостоятельная проверка проекта

> История Go-издания: упоминания Go-команд, путей и цифр ниже относятся к Go-реализации (ai386).

Запрос 2026-10-14: «проверь все что можешь самостоятельно».

Критерий: проверить все доступные автоматические и гостевые пути, выявить
реальные пробелы доказательств, исправить подтверждённые дефекты с регрессией,
сохранить воспроизводимые команды и честно отделить внешние ограничения.
Предыдущая полная приёмка Doom и общие test/race/vet/build учитываются;
без изменений или новых сомнений их не повторяем ради повторения.

## Независимые направления

| Направление | Владелец | Область | Завершение |
| --- | --- | --- | --- |
| CPU/FPU | cpu_verification | матрицы M/X, conformance, эталоны, гостевые FPU | фактические проверки и точная карта остающихся пробелов |
| SB16 | audio_verification | DSL/FreeBSD playback/capture через file | содержимое PCM/recording, штатный shutdown, подтверждённый результат |
| Сеть | network_verification | гостевые DHCP/DNS/HTTP/HTTPS, NAT | реальные ответы обеих ОС и отсутствие незапрошенных входящих соединений |
| Платформа/ввод | root | opt-in инвентарь, GUI 100МГц, сборки/CLI/диски | все применимые оставшиеся проверки с артефактами |
| Интеграция/review | root + независимый reviewer | новые изменения и сводка | необходимые ctest/clang-tidy/сборка CMake/strict validate и отсутствие high/blocking findings |

Каждый guest использует отдельную копию HD. Исходные образы, конфиги и
предшествующие незакоммиченные изменения сохраняются. Нельзя подменять
гостевые маркеры эхом ввода, PCM тишиной, HTTPS одним TCP connect.

Сначала исследование и выбор конкретного сценария, затем тесты/прогоны.
Изменения production — после red-регрессии и scoped OpenSpec design.
Владельцы не редактируют файлы другого направления без координации.

Физический звук требует настоящего устройства и слышимого подтверждения;
Windows runtime требует Windows host. Проверим фактическую доступность,
сборку/интеграцию не объявим заменой этих критериев.
