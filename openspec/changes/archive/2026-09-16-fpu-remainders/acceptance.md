# Приёмка

> История Go-издания: упоминания Go-команд, путей и цифр ниже относятся к Go-реализации (ai386).

`go test ./...`: PASS (CPU6.361 с), `go vet ./...` и `go build ./...`: PASS. `go test -race ./internal/cpu`: PASS42.597 с. OpenSpec strict PASS.

`reference.c` исполняет native x87 на хосте; `reference.txt` содержит результаты FPREM/FPREM1 для делимого−9…9 и делителя2. Подтверждены signed zero и quotient flags для отрицательных значений. Хостовый x87 используется как дополнительная сверка этих операций, не объявляется эталоном всего i486.

Юниттесты проверяют те же граничные значения, все RC при PC24,64-битную мантиссу, частичную редукцию большого порядка с C2 и завершение, invalid/denormal и unmasked сохранность стека. Общая задача полноты FPU2.8 остаётся открытой.
