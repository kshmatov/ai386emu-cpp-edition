## Context
Пользователь согласовал VGA+VBE640×480/256 с QEMU/SeaBIOS. Нормативный источник: VESA VBE Core Functions2.0 rev1.1 (включает банковый интерфейс1.2), https://www.phatcode.net/res/221/files/vbe20.pdf.

## Decisions
Интерфейс VBE1.2, режим101h. Использовать существующие четыре плоскости по128 КиБ как512 КиБ линейной памяти расширенного режима. ОкноA0000–AFFFF, восемь банков по64 КиБ; отдельного LFB нет. Формирование кадра учитывает логическую строку и начало изображения. DAC остаётся6-битным.

Функции BIOS00–08: информация, modeinfo, установка/текущий режим, save/restore, банк, строка, начало, DAC. Информация сообщает только101h; WinFuncPtr допускаетсяNULL, переключение черезINT10h. Невалидные значения проверяются до изменения состояния. Сохранение аппаратных, BIOS, DAC и расширенных регистров раздельно управляется CX; видеопамять в снимок не включается. Зарезервированные поля блоков обнуляются.

## Risks
Границы банков и последнего видимого пикселя проверяются тестами. Restore должен отклонять некорректный блок до изменения состояния. Существующие режимы должны отключать VBE только после успешного SetMode. Преобразование DAC/RGB уже отличается от QEMU; сравнение записывает обе точности и не скрывает RGB-расхождение.
