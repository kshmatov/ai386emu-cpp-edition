# Приёмка far data loads

2026-09-11. Регрессии operand/selector/descriptor/accessed/invalid для пяти загрузок указателя,16/32бит, и POP sreg выявили раннюю запись GPR/SP. После исправления состояние фиксируется только после успешного loadSegment; публичный SetSeg совместим. Отдельно проверены все сочетания прежнего/нового SS.B и operand size при POP SS. read32 прекращается на первом PF.

При подготовке тестов исправлено ошибочное отображение тестовой страницы 0x4000→0x40000; корректная матрица проходит. Общие test/vet/build успешны (CPU6.121с), CPU race43.504с, OpenSpec strict61/61. Interrupt shadow после загрузок SS остаётся отдельным пунктом аудита.
