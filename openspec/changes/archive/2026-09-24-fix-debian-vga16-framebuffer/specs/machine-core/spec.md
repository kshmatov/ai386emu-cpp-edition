## ADDED Requirements

### Requirement: Framebuffer установщика Debian Sarge

Машина SHALL загружать оригинальный Debian 3.1r8 Sarge i386 netinst ISO с SHA256 `5cee250e89b2993cf9053c74602868f45b6d1b1386d41803dba42c6622a4558e` штатной командой `linux` и отображать рабочий интерфейс установщика через `vga16fb` без параметра `debian-installer/framebuffer=false`.

#### Scenario: Выбор языка в графическом framebuffer

- **WHEN** Debian загружен командой `linux` с RAM 128 МиБ и boot order `cd,hd`
- **THEN** видимый кадр имеет геометрию 640×480 и содержит полноценный экран `Choose a language`, а не только заголовок или чёрный фон
- **AND** пример принятого кадра содержит фон, рамку, список языков и выделенный пункт

#### Scenario: Переход между начальными экранами

- **WHEN** пользователь подтверждает язык, страну и раскладку через PS/2-клавиатуру
- **THEN** установщик переходит к следующему экрану после каждого подтверждения
- **AND** каждый новый framebuffer-кадр остаётся непустым и читаемым
