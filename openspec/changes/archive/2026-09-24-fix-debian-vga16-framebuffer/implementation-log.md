# Журнал реализации

> История Go-издания: упоминания Go-команд, путей и цифр ниже относятся к Go-реализации (ai386).

## 2026-09-23T21:34:49+03:00 — задачи 1.3, 2.1, 2.2

- Реализованы VGA Read Mode 1, Color Compare и Color Don't Care; чтение загружает четыре латча.
- Графические planar, chained и unchained кадры учитывают CRTC Start Address и Offset с 16-битным замыканием адреса.
- Стандартные графические BIOS-режимы программируют CRTC Offset.
- Проверки: `go test ./internal/vga -count=1` и `go vet ./internal/vga` — успешно (`GOCACHE=/tmp/ai386-go-cache-vga16`).
- Время этапа: около 25 минут с исследованием первичных исходников Linux 2.4.27 и QEMU.
- Токены: среда выполнения не предоставляет точный счётчик по отдельной задаче.
- Replay BOGL/fbcon из задачи 1.1 уже проходит на исходной реализации write modes; поэтому задачи 1.1/1.2 оставлены открытыми до причинной диагностики реального гостя.

## 2026-09-23T21:42:00+03:00 — задача 3.1

- Добавлен opt-in режим приёмки Debian framebuffer: три устойчивых структурно содержательных кадра 640×480, переходы через PS/2 Enter, пространственное сравнение кадров и PNG при успехе/ошибке.
- Синтетические `testify`-тесты отвергают чёрный кадр и прежний вариант с одним заголовком, принимают полноценный диалог и игнорируют единичное мигание.
- Проверки: профильные `go test ./internal/machine` и `go vet ./internal/machine` — успешно.
- Время: около 15 минут. Точный расход токенов среда выполнения не предоставляет.

## 2026-09-23T22:18:00+03:00 — задачи 1.1 и 1.2

- Device-level и CPU→VGA replay подтвердили корректность BOGL/fbcon write modes, включая wide store и byte RMW.
- Реальная диагностика показала содержательный VRAM при чёрном кадре и `AC Mode Control=0x81`; выявлена отсутствующая семантика P54S/Color Select при преобразовании AC palette в индекс DAC.
- Реализовано формирование DAC-индекса: Color Select[3:2] задаёт биты 7-6, а при P54S Color Select[1:0] заменяет palette bits 5-4.
- Добавлены `testify`-регрессии на общий Color Select и точное состояние Linux VGA16; `go test ./internal/vga` и `go vet ./internal/vga` проходят.
- Время: около 35 минут диагностики и исправления. Точный расход токенов среда выполнения не предоставляет.

## 2026-09-23T23:26:39+03:00 — задачи 3.2 и 3.3

- Opt-in приёмка Debian 3.1r8 с командой ровно `linux` прошла для экранов языка, страны и раскладки на 1 120 000 000, 1 268 000 000 и 1 419 000 000 инструкций.
- Все три PNG просмотрены вручную; кадры читаемы, а переходы выполнены через PS/2 Enter. Контрольная сумма ISO и снимков записана в `acceptance.md`.
- Критерии кадра дополнены регрессиями для boot log, пустой панели, частично очищенного экрана и узкого штатного диалога раскладки.
- README теперь рекомендует штатную команду `linux` и ссылается на новый отчёт; требование `debian-installer/framebuffer=false` удалено из актуальной документации.
- Контрольный гостевой прогон: успешно, 592,16 с. Суммарное время этапа с уточнением критериев приёмки — около 80 минут. Точный расход токенов среда выполнения не предоставляет.
