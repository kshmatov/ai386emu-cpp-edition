## Context

FreeBSD miniinst остановился до первой инструкции, поскольку media=3 отклонялся.

## Goals / Non-Goals

Поддержать BIOS-эмуляцию встроенной дискеты. ATAPI/FDC не перенастраиваются; новый файл образа не создаётся.

## Decisions

В BIOS добавляется read-only представление storage.BlockDevice: 512-байтовый сектор соответствует четверти сектора CD с учётом image LBA. Альтернатива — извлечь файл и подключить FDC — меняет внешнюю конфигурацию и обходит семантику CD.

Bootstrap изменяет ту же карту DL, которую использует обработчик INT 13h; геометрия встроенного образа хранится в BootDevice. При наличии обычной дискеты она сдвигается с DL=0 на DL=1. BDA equipment отражает наличие дискет.

## Risks / Trade-offs

Границы образа проверяются до передачи управления. Указатели на сектор CD не передаются гостю напрямую. Запись запрещена. Старый no-emulation и HD покрыты регрессиями.
