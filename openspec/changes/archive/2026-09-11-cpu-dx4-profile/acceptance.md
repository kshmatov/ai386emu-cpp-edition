# Приёмка профиля IntelDX4

> История Go-издания: упоминания Go-команд, путей и цифр ниже относятся к Go-реализации (ai386).

2026-09-11. Исходные регрессии CPUID/reset/ID/paging FAIL; после исправления PASS. CPUID проверена в real/protected/CPL3/VM86, LOCK вызывает #UD. ID проходит POPFD/PUSHFD и IRETD real/protected, reset даёт signature 00000480h. Stepping 0 — виртуальная ревизия, не физические errata.

Удалён путь 4 МиБ. Матрица WP/CPL/PDE/PTE сохранена и проверяет двухуровневый обход с обоими значениями зарезервированного PDE bit7. Отдельно проверены missing PDE/PTE, права и A/D. Старые тесты больших страниц заменены соответствующими тестами выбранного профиля.

Общий go test ./... PASS (CPU 6.935с); go vet ./... и go build ./... PASS. Дополнительные режимы CPUID/IRETD PASS. CPU race 42.236с, Machine race 1.351с PASS. Раннер conformance не изменялся. Strict PASS.

Полная гостевая HD-приёмка на новой идентификации остаётся обязательной в cpu-functional-completion 5.2; прежние отчёты ОС не выдаются за новый прогон. Полнота CR/TR/debug/FPU этим изменением не закрыта. Источники сохранены в CPU-спецификации.
