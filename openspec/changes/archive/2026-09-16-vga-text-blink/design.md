## Решение
AC10 bit3 включает blink для attr bit7; невидимая фаза выводит фон. При выключении остаётся яркий фон. Полуфаза16 кадров, номинальная текстовая развёртка70Гц; Machine переводит существующие RTC ticks32768Гц в кадры с остатком. Frame не двигает время. Источник16 кадров: Video7 VGA Technical Reference Jun1988, Attribute Mode Control.

Курсор также имеет16-кадровую фазу и сохраняет CRTC disable. Полный расчёт аналоговой развёртки CRTC не добавляется. QEMU8.2.2 не реализует мигание символов (vga_draw_text использует cattr без blink); поэтому сравнение статического кадра остаётся QEMU, временной контракт проверяется тестами по руководству устройства.

Источник: https://oummg.com/manual/700-0242_V7_VGA_Technical_Reference_Manual_Jun88.pdf .
