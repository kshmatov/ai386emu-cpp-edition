## Why

Этап 3 завершил подсистему хранения (IDE, floppy, shared CD). Сейчас CPU после сброса находится в аппаратном состоянии CS=0xF000/EIP=0xFFF0 — адресе, где на реальном железе лежит BIOS ROM. У эмулятора нет ни BIOS, ни процесса начальной загрузки: физически по этому адресу нет кода, и ни один образ операционной системы не может быть загружен и исполнен.

Этап 4 реализует минимальный BIOS реального режима: набор нативных сервисов (INT 10h/13h/15h/16h), выполненных как обработчики на стороне эмулятора (а не как исполняемый гостем x86-код), и процесс начальной загрузки — чтение загрузочного сектора с первого подходящего устройства из очереди `--boot` и передачу управления загруженному коду. Критерий этапа — довести реальный режим минимум до момента, когда загруженный код переключает процессор в защищённый режим.

## What Changes

- Новый пакет `internal/bios`: нативные обработчики программных прерываний INT 13h (дисковые сервисы: CHS и LBA-чтение/запись, параметры дисков, поверх `storage.BlockDevice`), INT 10h (минимальная заглушка teletype/смены режима — полноценный вывод появится на этапе VGA), INT 16h (заглушка клавиатуры — полноценный ввод появится на этапе input), INT 15h (карта памяти E820, включение линии A20 как no-op)
- Процесс начальной загрузки: выбор устройства по очереди `--boot`; для hd/floppy — чтение сектора 0 и проверка сигнатуры 0x55AA; для cd — разбор El Torito boot catalog (только режим no-emulation) поверх уже существующего ISO9660; копирование загруженного кода в память по адресу 0x7C00 и передача управления (CS=0000, IP=7C00, DL=номер BIOS-диска)
- Расширение `internal/cpu`: точка перехвата программных прерываний (`SetSoftIntHook`) — при её наличии для вектора INT инструкция обрабатывается нативно вместо доставки через IVT
- Изменение поведения `Machine.Start()`: после `cpu.Reset()` выполняется нативный bootstrap (регистрация хуков + загрузка ОС) вместо остановки на адресе аппаратного сброса без исполняемого кода

## Capabilities

### New Capabilities

- `bios`: нативные BIOS-сервисы реального режима (INT 10h/13h/15h/16h) и процесс начальной загрузки ОС с устройства из очереди `--boot`, включая El Torito (no-emulation) для CD

### Modified Capabilities

- `machine-core`: сценарий запуска машины меняется — вместо остановки на адресе аппаратного сброса выполняется загрузка загрузочного сектора и передача управления

## Impact

- Новый пакет: `internal/bios`
- Изменяемые пакеты: `internal/cpu` (точка перехвата INT), `internal/machine` (bootstrap вместо голого reset)
- Зависимости: нет новых внешних зависимостей
- Не реализуется в рамках этого этапа (см. design.md Non-Goals): El Torito floppy/HD-emulation режимы CD, полноценный вывод VGA, полноценная клавиатура, эмуляция аппаратного A20 gate
