## MODIFIED Requirements

### Requirement: Служебные сервисы BIOS (INT 15h)

Эмулятор SHALL предоставлять сервис карты памяти (E820h) и обработку запросов включения линии A20 как всегда успешную операцию.

#### Scenario: Запрос карты памяти
- **WHEN** гостевой код вызывает INT 15h AX=E820h
- **THEN** BIOS SHALL перечислять непересекающиеся регионы: доступный [0, min(RAM, 640 КиБ)), зарезервированный [640 КиБ, min(RAM, 1 МиБ)), доступный [1 МиБ, RAM). Пустые регионы не возвращаются; EBX начинает перечисление с 0, содержит продолжение после промежуточной записи и 0 после последней

#### Scenario: Включение линии A20
- **WHEN** гостевой код запрашивает включение линии A20 (INT 15h AX=2401h, порт 0x92 или контроллер 0x64/0x60)
- **THEN** запрос завершается успешно

#### Scenario: Неверное продолжение
- **WHEN** передан недопустимый E820 continuation token
- **THEN** BIOS SHALL установить CF и не записывать дескриптор
