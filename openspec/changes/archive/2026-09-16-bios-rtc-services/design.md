## Context
Диагностический вход вместо нулевого IVT1A подтвердил AX=0200 после 68357032 инструкций FreeBSD.

## Goals / Non-Goals
Переиспользовать RTC через порты, не создавать второй календарь.

## Decisions
Интерфейс шины BIOS включает In/Out, уже реализованные machine.Bus и тестовой шиной. Чтение CMOS сохраняет выбранный индекс и NMI-mask. Значения нормализуются в BCD/24 часа для BIOS ABI. Обновление RTC не происходит внутри одной native-инструкции, поэтому снимок согласован.

## Risks / Trade-offs
Нужны проверки binary/12-hour, UIP и индекса CMOS, чтобы BIOS не менял настройку гостя. Неизвестные функции возвращают ошибку.
