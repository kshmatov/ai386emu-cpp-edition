# Tasks: Хранение — IDE, floppy, shared CD (этап 3)

> История Go-издания: упоминания Go-команд, путей и цифр ниже относятся к Go-реализации (ai386).

Выполнение — отдельным субагентом в ветке git-flow `feature/storage-ide-floppy`. После каждой задачи фиксируется запись (время и токены). Каждая задача сопровождается тестами (testify) и прогоном `go test ./...`, `go vet ./...`.

## 1. Block device и образы HD/floppy

- [x] 1.1 Интерфейс `BlockDevice` (`internal/storage/block.go`): `ReadSector(n) ([]byte, error)`, `WriteSector(n int, data []byte) error`, `SectorSize() int`, `NumSectors() int`, `ReadOnly() bool` (критерий приёмки: юнит-тесты интерфейса через фейковую реализацию; сценарии «Чтение сектора», «Запись сектора на read/write устройство», «Запись на read-only устройство»).
- [x] 1.2 `rawDataStore` (`internal/storage/raw.go`): файловый backed, 512 байт/сектор; при отсутствии файла — создание (`os.Create`+`Truncate`) до указанного размера, заполненного нулями; при наличии — использование без изменения размера; чтение/запись секторов (критерий приёмки: тесты создания нового образа, использования существующего, чтения/записи данных; сценарии раздела «Образ жёсткого диска (raw)»).
- [x] 1.3 Валидация размера floppy-файла (1 474 560 байт = 1.44M) при подключении существующего файла (критерий приёмки: тест на неверный размер → понятная ошибка при старте; сценарий «Неверный размер файла»).

## 2. CD: ISO-файл и виртуальный ISO для shared

- [x] 2.1 `isoDataStore` (`internal/storage/iso.go`): парсинг Primary Volume Descriptor (sector 16) и directory records стандартного ISO9660, 2048 байт/сектор, только для чтения, чтение секторов из файла-образа (критерий приёмки: тесты на синтетическом/тестовом ISO — чтение PVD, чтение секторов данных, отказ записи; сценарии раздела «CD-ROM (ISO9660 image)»).
- [x] 2.2 `virtualIsoStore` (`internal/storage/iso_virtual.go`): при старте — однократный обход каталога хоста, построение в памяти PVD + дерева directory records + таблицы «LBA-диапазон → (host-путь, смещение)»; данные файлов не копируются — чтение сектора вне метаданных выполняется напрямую из host-файла через `os.File.ReadAt`; временный `.iso`-файл на диск не пишется (критерий приёмки: тесты на каталог с несколькими файлами и подкаталогами — чтение метаданных и данных, отсутствие временного файла на диске, отказ записи, неизменность содержимого после старта при изменении каталога хоста «на лету»; сценарии раздела «CD-ROM из каталога хоста (shared)»).

## 3. IDE-контроллер (PIO)

- [x] 3.1 Каркас `IDEController` (`internal/storage/ide.go`): регистры (data, error/features, sector count, LBA low/mid/high, drive/head, status/command, alt status/control), два канала — primary (0x1F0–0x1F7, 0x3F6) и secondary (0x170–0x177, 0x376), выбор master/slave через drive/head (критерий приёмки: тесты маршрутизации портов к каналам и выбора устройства; сценарии «Порты primary канала», «Порты secondary канала»).
- [x] 3.2 Команда IDENTIFY DEVICE (0xEC): формирование 512-байтного identify-блока (число секторов, модель, поддерживаемые режимы), выставление DRQ, чтение блока через data-регистр (критерий приёмки: тест содержимого блока и последовательности статусных бит; сценарий «Команда IDENTIFY DEVICE»).
- [x] 3.3 Команда READ SECTORS (0x20) с ретраями: LBA- и CHS-адресация, посекторное чтение через data-регистр с DRQ на каждый сектор, IRQ14 (primary) / IRQ15 (secondary) по завершении (критерий приёмки: тесты чтения одного и нескольких секторов, доставка IRQ; сценарии «Команда READ SECTORS», «IRQ14 для primary», «IRQ15 для secondary»).
- [x] 3.4 Команда WRITE SECTORS (0x30): запись данных на устройство с поддержкой записи (HD); отказ (ABRT в статусе) при попытке записи на устройство только для чтения (CD) (критерий приёмки: тесты записи на HD и отказа записи на CD; сценарий «Команда WRITE SECTORS»).
- [x] 3.5 Обращение к неподключённому устройству: status=0x00, BSY=0, DRQ=0 (критерий приёмки: тест обращения к Secondary Slave без подключённого устройства; сценарий «Обращение к несуществующему устройству»).

## 4. Floppy-контроллер (PIO)

- [x] 4.1 Каркас `FloppyController` (`internal/storage/fdc.go`): порты 0x3F0–0x3F7, регистры статуса/данных, геометрия 1.44M (80 треков, 2 головки, 18 секторов/трек, 512 байт/сектор) (критерий приёмки: тесты маршрутизации портов и геометрии; сценарий «Порты контроллера floppy»).
- [x] 4.2 Команды READ SECTOR / WRITE SECTOR: CHS-адресация, посекторный обмен через data-регистр, IRQ6 по завершении операции (критерий приёмки: тесты чтения и записи сектора, доставка IRQ; сценарии «Команда READ SECTOR», «Команда WRITE SECTOR», «IRQ6»).
- [x] 4.3 Команды RECALIBRATE и SENSE INTERRUPT STATUS (критерий приёмки: тест перемещения головки на дорожку 0 и корректного статус-ответа; сценарии «Команда RECALIBRATE», «Команда SENSE INTERRUPT STATUS»).

## 5. Интеграция: Machine, Bus, CLI, конфигурация

- [x] 5.1 CLI (`internal/cli`): новые флаги `--hd-size <size>`, `--shared <path>` (повторяемый), `--floppy <path>`; семантика `--cd <path>` меняется на ISO-файл (было — каталог) (критерий приёмки: тесты парсинга новых и изменённых флагов, повторяемость `--shared`).
- [x] 5.2 Config (`internal/config`): параметры TOML `HDSize`, `Shared` (список строк), `Floppy`; валидация — существование ISO-файла (`--cd`)/каталога (`--shared`)/floppy-файла, корректность размера floppy (критерий приёмки: тесты загрузки и валидации конфигурации; сценарии «CD-путь без файла», «CD-путь без каталога», «Неверный размер файла floppy», «Floppy без файла»).
- [x] 5.3 Machine (`internal/machine`): создание storage-устройств при старте — HD (`rawDataStore`, создаётся при отсутствии файла нужного размера через `--hd-size`), CD из `--cd` (`isoDataStore` на Primary Slave), shared CD из `--shared` (`virtualIsoStore` на Secondary Master, один на каждый путь), floppy из `--floppy` (`rawDataStore` на floppy-контроллере) (критерий приёмки: тесты `Machine.New`/`Start` с разными комбинациями подключённых устройств; сценарии «Создание нового образа HD», «Использование существующего образа», «Подключение ISO-файла как CD», «Подключение каталога как CD», «Подключение floppy-образа»).
- [x] 5.4 Bus: регистрация портов IDE (оба канала) и floppy-контроллера, подключение IRQ6/IRQ14/IRQ15 к существующему механизму прерываний CPU (критерий приёмки: тесты регистрации портов без конфликтов с уже занятыми диапазонами; спек-дельта `machine-core` покрыта).
