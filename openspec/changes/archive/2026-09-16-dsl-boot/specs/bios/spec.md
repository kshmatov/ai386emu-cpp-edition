## ADDED Requirements

### Requirement: Сервисы BIOS для загрузки DSL

BIOS SHALL обеспечивать загрузчику DSL 4.4.10 получение объёма обычной памяти через INT 12h и вывод текста через используемые функции INT 10h.

#### Scenario: Запрос обычной памяти
- **WHEN** загрузчик вызывает INT 12h
- **THEN** AX содержит число КиБ обычной памяти, ограниченное настроенной RAM и границей 640 КиБ; управление возвращается загрузчику

#### Scenario: Вывод загрузчика
- **WHEN** ISOLINUX выводит символы через AH=09h и управляет курсором через AH=02h/03h
- **THEN** символы с атрибутами появляются в текстовом кадре, повторная запись символа не сдвигает курсор

### Requirement: Воспроизводимая загрузка DSL

Эмулятор SHALL загружать выбранный пользователем образ DSL 4.4.10 через его штатный загрузчик. Приёмка SHALL различать запуск ISOLINUX, передачу управления Linux в protected mode и дальнейшую загрузку ядра.

#### Scenario: Переход реального Linux в protected mode
- **WHEN** выполняется загрузка выбранного ISO с зафиксированной конфигурацией
- **THEN** исполнение достигает protected-mode кода Linux; результат подтверждается адресом и состоянием CPU, а не только наличием boot signature или кодом завершения теста

#### Scenario: Определение оборудования и legacy-памяти
- **WHEN** Linux запрашивает INT 11h, INT 15h AX=E801h или AH=88h
- **THEN** BIOS возвращает конфигурацию оборудования и размеры памяти согласно настроенной RAM; неподдерживаемые функции INT 15h возвращают CF=1 и AH=86h
