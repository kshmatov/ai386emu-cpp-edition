## ADDED Requirements

### Requirement: Переход Linux через LMSW

CPU SHALL исполнять LMSW r/m16, изменяя только биты 0–3 CR0 и сохраняя уже установленный PE.

#### Scenario: Включение PE
- **WHEN** Linux setup исполняет LMSW с установленным битом 0 операнда
- **THEN** CR0.PE устанавливается, остальные биты выше 3 сохраняются и следующий far jump может загрузить protected-mode CS

#### Scenario: Недостаточные привилегии
- **WHEN** LMSW исполняется с CPL, отличным от 0
- **THEN** возникает #GP(0), CR0 не меняется

### Requirement: Ширина адресов переходов и возвратов Linux

CPU SHALL сохранять 32-битный EIP при дальнем JMP и ближнем RET с 32-битным размером операнда независимо от размера адреса памяти.

#### Scenario: Дальний переход setup в декомпрессор
- **WHEN** 16-битный setup выполняет JMP ptr16:32 с префиксом 66h к плоскому code-сегменту и смещению 0x100000
- **THEN** EIP становится 0x100000, без усечения до 16 бит

#### Scenario: Возврат из 32-битной функции
- **WHEN** RET извлекает 32-битный адрес возврата 0x101E76 из допустимого стека
- **THEN** EIP становится 0x101E76, а ESP продвигается на 4 байта

#### Scenario: Косвенный вызов 32-битной функции
- **WHEN** Linux выполняет CALL r/m32 к адресу выше 64 КиБ
- **THEN** EIP получает полный адрес, на стек помещается полный 32-битный адрес возврата

### Requirement: Определение i486 через флаг AC

CPU SHALL разрешать изменение AC через 32-битный POPFD, позволяя гостю отличить i486 от i386.

#### Scenario: Проверка AC при старте Linux
- **WHEN** Linux изменяет бит 18 сохранённых EFLAGS через POPFD и читает результат через PUSHFD
- **THEN** новое значение AC сохраняется; флаг ID не объявляет неподдержанную CPUID

### Requirement: Инициализация отладочных регистров Linux

CPU SHALL исполнять привилегированные MOV DR0–DR3/DR6/DR7, сохраняя аппаратные значения зарезервированных битов DR6/DR7; DR4/DR5 SHALL быть псевдонимами DR6/DR7 на i486.

#### Scenario: Очистка debug-регистров при старте CPU
- **WHEN** Linux пишет нули в DR0–DR3/DR6/DR7 через MOV DRn,r32 при CPL=0
- **THEN** регистры обновляются, в DR6 сохраняются зарезервированные единицы 0xFFFF0FF0, в DR7 — бит 10

#### Scenario: Защита debug-регистров
- **WHEN** MOV DR выполняется при CPL>0
- **THEN** возникает #GP(0) без изменения debug-регистра
