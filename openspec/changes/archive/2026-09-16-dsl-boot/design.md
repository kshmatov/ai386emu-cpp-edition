## Context

DSL ISO: 52328448 байт, El Torito no-emulation, каталог LBA 24734, образ LBA 24739, начальная загрузка 4 сектора по 512 байт. Machine.Run завершён предыдущим change.

## Goals / Non-Goals

Воспроизвести загрузку из исходного ISO; не подменять загрузчик синтетическим кодом и не считать успешное создание ВМ загрузкой ОС.

## Decisions

Исполнять оригинальный загрузчик, фиксировать обращения BIOS и место остановки. Для каждого блока — минимальная регрессия, исправление, повторный ISO-прогон, полные тесты и линтеры. Источник семантики BIOS: реализация SeaBIOS (src/system.c, vgasrc/vgabios.c); фактические потребности определяются машинным кодом ISOLINUX в ISO.

## Risks / Trade-offs

- Таймеры, карта памяти и устройства могут потребовать дальнейших доработок: выявленные блокеры записываются и исправляются до заявленной точки приёмки.
- Локальный ISO не включается в Git; воспроизводимость обеспечивается SHA256 и явным путём.

Для первого прогона используется штатный пункт `dsl-txt` из ISOLINUX.CFG: vga=normal соответствует VGA. Пункт по умолчанию требует vga=791 (VESA framebuffer), что выходит за текущий VGA-контракт. ISO не меняется.
