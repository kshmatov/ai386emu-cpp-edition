# Проверка XADD

> История Go-издания: упоминания Go-команд, путей и цифр ниже относятся к Go-реализации (ai386).

Регрессии до исправления подтвердили три дефекта:

- 0F C0/C1 потребляли байт следующей команды как immediate; INC BX после XADD не выполнялась во всех трёх размерах операнда.
- FFFFFFFFh + 1 давало ноль без CF.
- XADD [SI],SI при SI=4 записывала результат по DS:10 вместо DS:4.

После исправления все регрессии проходят. Отдельно проверено XADD AX,AX: результат равен удвоенному исходному значению.

Полный go test ./... -count=1, go vet ./... и go build ./... успешны. go test -race ./internal/cpu -count=1 успешен (40.560 с). OpenSpec strict: 25/25, git diff --check без ошибок.

Это продолжение 2.2, а не приёмка всего набора команд: в таблице group7Op отсутствует SMSW (0F 01 /4). Остальные открытые задачи roadmap не закрывались.
