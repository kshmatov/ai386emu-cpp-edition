## ADDED Requirements

### Requirement: Рабочий текстовый shell DSL с оригинального ISO
Машина SHALL загружать оригинальный DSL 4.4.10 ISO с SHA256 `6d9369c7b8fb0f23880c5ec44f5a4a2d9d628d7a1407ea83bf0b3249eda33537` при RAM=64 МиБ и boot order=cd через штатный пункт `dsl-txt 2` до текстового shell. Ввод SHALL проходить через PS/2, результат SHALL отображаться на VGA без изменения образа или перехвата программ гостя.

#### Scenario: Выполнение команды в shell
- **WHEN** после загрузки через гостевую клавиатуру введено `echo ai386ready`
- **THEN** на видимом экране появляется отдельная строка `ai386ready`
- **AND** одно лишь отображение набранной команды не считается успешным выполнением
