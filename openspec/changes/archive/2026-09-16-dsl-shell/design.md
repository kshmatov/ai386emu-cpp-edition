## Context

См. proposal.md. TestDSLDiagnostic уже проверяет неизменность ISO и точку входа в ядро.

## Decisions

Расширить тест опциональной строгой проверкой shell. Наблюдать видимые текстовые клетки VGA; после приглашения отправить скан-коды команды через Machine.KeyEvent и проверять отдельную строку результата. Сохранять PNG и журнал диагностики. Без внешнего ISO обычный тест пропускается; приёмка ОС запускается отдельной явной командой.

Не использовать подмену EIP, патчи гостевых программ или хуки системных вызовов для прохождения загрузки.

## Risks / Trade-offs

Прогон дорогой: несколько сотен миллионов и более инструкций. Устанавливается ограничение шагов и таймаут; их исчерпание без результата означает FAIL строгой приёмки. Обычный диагностический режим остаётся пригодным для локализации промежуточных блокеров.
