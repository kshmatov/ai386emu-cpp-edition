# Отложенные проверки для следующего релиза

Состояние зафиксировано 2026-09-16. Реализация и принятые guest-прогоны
сохраняются в этом архиве; незавершённые проверки не объявляются выполненными.

## Отложено

- 5.4a: полная матрица M всех допустимых integer-форм, включая все оси
  режимов, размеров, адресации, прав, fault/restart и определённых флагов.
- 5.4b: полная матрица X всех допустимых x87-форм, включая численные классы,
  PC/RC, TOP, маски, memory fault, waiting/no-wait и приоритет исключений.
- 5.4c: синхронизация итогового CPU-контракта с базовой спецификацией после
  завершения M/X. Решения Intel имеют приоритет; reserved и undefined формы
  не превращаются в обязательные эталоны.
- Итоговая задача 5.4 и закрытие roadmap 2.2/2.8/2.5.

## Зафиксировано в текущем релизе

- Linux/DSL и FreeBSD i386 загружаются с HD; гостевые FPU-прогоны,
  штатная остановка и повторная загрузка приняты.
- Исправлены и покрыты принятые scoped-контракты CPU/FPU, включая FIST/FISTP
  по Intel: изолированная немаскированная PE записывает округлённое значение
  и выполняет предусмотренный pop.
- Для FBLD цифры A–F результат считается архитектурно неопределённым по Intel;
  IE не является обязательным требованием.
- Для регистровых x87 форм 66h/67h без применимого операнда или адреса
  кодировка reserved по Intel; существующие тесты таких комбинаций являются
  регрессиями эмулятора.
