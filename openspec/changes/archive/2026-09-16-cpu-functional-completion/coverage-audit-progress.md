# Сверка полноты CPU/FPU: промежуточный результат 2026-09-16

> История Go-издания: упоминания Go-команд, путей и цифр ниже относятся к Go-реализации (ai386).

Исходная сборка: `09f632a`. Задача 5.4 остаётся открытой. Принятые
5.1–5.3 и обе гостевые FPU-сессии сохраняются, но не доказывают каждую
допустимую форму из матриц M и X. Этот отчёт фиксирует проверенные находки,
а не итоговую приёмку этапа 2.

- [integer-inventory.md](integer-inventory.md) требует матрицу M по формам,
  размерам, адресации, режимам, правам, faults и restart. Большинство строк
  всё ещё явно имеют статус частичного покрытия. Нельзя заменить её общим
  conformance-прогоном 80386 или принятыми HD-сессиями.
- [x87-inventory.md](x87-inventory.md) требует матрицу X по формам D8–DF,
  PC/RC, классам raw80, маскам, TOP, памяти и исключениям. Scoped задачи
  2–4 выполнены, но полный X для каждой строки ещё не сопоставлен с тестом.
- `DC D0–DF` исполняются как недокументированные алиасы FCOM/FCOMP. Таблица
  Intel DX4 не включает их в документированные формы и не предписывает
  обязательный #UD. Их поведение не засчитывается как покрытие допустимой X.
- Для `MOV DR` Intel задаёт выбор GPR полем `ModR/M.r/m` при любом `mod`;
  проверены длина команды и отсутствие чтения memory-looking адреса.
  Приоритет совместных GD и CPL3 ещё требует аппаратного эталона.
- Проверка writable segment добавлена к общим memory destinations и
  специализированным selector/table store; ADD/ADC/SUB/SBB/AND/OR/XOR
  проверяют право до изменения флагов. Для этих ALU-команд, INC/DEC/NEG,
  shift/rotate и BTS/BTR/BTC добавлена предварительная проверка page write;
  доказаны отдельные случаи ADD, INC/DEC/NEG, SHL/SHLD, BTS/BTR/BTC.
  Атомарность остальных форм и сочетаний прав остаётся частью M.
- [Базовая спецификация CPU](../../specs/cpu/spec.md) пока содержит
  промежуточное исключение FPU и правило #UD для отсутствующей реализации.
  После полного M/X итоговая дельта должна заменить его, сохранив точные
  scoped требования к NaN, исключениям, контексту и системным механизмам.
  Дельта и базовая спецификация уже содержат исправленное требование
  precision commit для integer/BCD store; остальные промежуточные
  ограничения базы изменятся при итоговой синхронизации.
  Дельта `fpu-initialization` тоже содержит старое `MODIFIED` правило;
  порядок синхронизации должен оставить итоговую редакцию последней.
