# Приёмка IRQ shadow

2026-09-11. Регрессии STI/MOV SS/POP SS/PIC до исправления падали: IRQ поступал раньше следующей инструкции. После исправления следующая инструкция завершает обновление стека, запрос сохраняется, PIC не опрашивается. Проверены STI;HLT, IF уже установлен, failed SS, LSS без shadow, fault/reset.

Дополнительно выявлена неверная передача отказа checkIOPL: raiseException возвращает0 циклов, и вызывающие функции продолжали инструкцию. Проверка теперь возвращает bool; CLI/STI/IN/OUT регрессии подтверждают отсутствие изменения IF/GPR/портов после GP. Тот же контракт применён к string I/O.

Общие test/vet/build успешны (CPU7.189с), race CPU49.836с/machine1.374с, strict PASS. Прежний тест IRQDeliveredAfterSTI исправлен: сохранённый IP должен указывать после NOP, а не на NOP. NMI и debug traps остаются вне этого завершённого объёма.
