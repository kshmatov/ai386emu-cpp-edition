## Context

DSL смонтировал initrd EXT2 и достиг EIP 08048074, но обработчик INT 80h не доставлен из-за U/S проверки.

## Decisions

Трансляция принимает явный признак user доступа. Обычные операнды продолжают использовать CPL; внутренние чтения IDT/GDT/TSS — supervisor. Запись кадра нового стека проверяется по целевому CPL. CR0.WP и present по-прежнему проверяются, физический обход paging не применяется.

## Validation

Регрессия INT80/IRETD: код и стек user доступны CPL3, все таблицы и kernel stack доступны только supervisor; после возврата прямое чтение IDT из user должно давать #PF U/S.
