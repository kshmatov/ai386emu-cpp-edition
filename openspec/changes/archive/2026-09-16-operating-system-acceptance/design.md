## Context

Пара ОС и размеры согласованы пользователем 2026-09-11. DSL уже проходит до shell с live-CD. FreeBSD miniinst использует El Torito floppy emulation 2,88 МиБ; первоначальный запуск останавливается в BIOS до исполнения гостя.

## Goals / Non-Goals

Воспроизводимая приёмка оригинальных загрузчиков и установленных гостей. Длительные ISO-прогоны запускаются явно и не входят в обычный go test без образа.

## Decisions

Использовать отдельные raw-HD, создаваемые Machine. Начальная очередь cd,hd, после установки hd,cd. Для диагностики использовать пошаговый запуск с отчётом VGA/регистров; для установки — оконный frontend и ввод через PS/2. Прямая запись маркера хостом не доказывает сохранение гостевых данных.

## Risks / Trade-offs

- Долгая загрузка → ограничение числа шагов и отчёты контрольных точек; исчерпание лимита означает неуспешный критерий.
- Неизвестные инструкции/BIOS-сервисы → отдельные scoped changes с регрессиями.
- Существующий HD → использовать отдельные пути, не перезаписывать данные пользователя.
