## Why
Machine молча игнорирует дополнительные ISO и третий каталог. Пользователь согласовал максимум три CD и явную ошибку при превышении.

## What Changes
Каждый допустимый ISO/каталог подключается к IDE; общий лимит проверяется до создания HD и запуска ВМ. Пользователь подтвердил контракт shared-CD: дерево фиксируется, содержимое читается с хоста. Спецификация и README согласованы с дизайном.

## Capabilities
### Modified Capabilities
- `config-cli`: общий лимит CD и доступность каждого пути.
- `storage`: размещение всех CD из каталогов на свободных IDE-слотах.

## Non-goals
Новые контроллеры, смена носителя во время работы и сеть.

## Impact
Config, Machine, интеграционные тесты и гостевая приёмка CD.
