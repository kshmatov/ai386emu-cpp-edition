## 1. Диски

Лимит согласован пользователем. Дизайн не требуется: распределение существующих устройств по трём существующим слотам; ранее поддержанные конфигурации сохраняют адреса.

- [x] 1.1 Проверить лимит в Config и Machine до создания HD, подключить каждый допустимый путь. Приёмка: регрессии смешанных конфигураций и превышения FAIL до исправления, PASS после; время и токены.
- [x] 1.2 Проверить чтение каждого CD через ATAPI и CD-драйвер гостевой ОС, общий test/vet/build и race config/machine. Приёмка: содержимое каждого настроенного носителя доступно, записи отклоняются; время и токены.

- [x] 1.3 Уточнить противоречие статичности shared-CD и ленивого чтения содержимого: получить решение пользователя, согласовать спецификацию/дизайн, подтвердить выбранный контракт тестами. Пользователь подтвердил: фиксировать дерево, читать содержимое с хоста.
