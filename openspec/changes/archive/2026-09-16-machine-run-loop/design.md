## Context

Start выполняет сброс и bootstrap; CPU.Run(n) уже доставляет IRQ и возвращает управление на HLT. Устройства и CPU пока не поддерживают конкурентный доступ.

## Goals / Non-Goals

Цель — один владелец исполнения CPU и закрытие ресурсов после его завершения. Параллельный доступ к RAM, CPU и API устройств не вводится этим change.

## Decisions

- Machine.Run(ctx) выполняет CPU синхронно после Start. Контекст проверяется между инструкциями; Stop отменяет цикл и ожидает его завершения перед Shutdown. Mutex защищает жизненный цикл. Отдельная постоянно работающая горутина CPU не нужна.
- HLT возвращает управление планировщику хоста с ожиданием до 1 мс или отмены. Это внутренняя пауза ожидания, не модель времени i486; таймеры будут спланированы в 1.6.
- main использует signal.NotifyContext для SIGINT/SIGTERM. CLI закрывает Machine и при ошибке Start. Контекст штатной остановки не является ошибкой пользователя.
- Тест CLI запускает настоящий процесс: загрузочный сектор пишет маркер на диск, тест дожидается маркера и посылает сигнал, затем проверяет успешный выход.

## Risks / Trade-offs

- Одна инструкция REP может быть продолжительной: остановка наблюдается между инструкциями; дробление REP требует отдельной проверки архитектурного состояния.
- HLT не является выключением машины: тестовые программы должны отменять контекст или посылать сигнал.
