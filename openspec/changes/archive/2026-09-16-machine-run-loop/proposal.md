## Why

CLI завершает работу сразу после bootstrap, поэтому загруженный код не исполняется. Для диагностической загрузки ОС нужен управляемый цикл исполнения (roadmap 1.5).

## What Changes

- После bootstrap CLI исполняет гостя до запроса остановки.
- SIGINT/SIGTERM завершают исполнение и закрывают носители; ошибка запуска также освобождает ресурсы.
- HLT приостанавливает CPU, сохраняя работающую ВМ.

## Non-goals

Таймеры платформы, окно и события ввода хоста, выбор образов ОС относятся к следующим этапам.

## Capabilities

### Modified Capabilities

- `machine-core`: непрерывное исполнение и согласованное завершение.

## Impact

Machine, CLI и интеграционные тесты. Новых внешних зависимостей нет. Приёмка: наблюдаемый результат гостя, отмена активного и halted CPU, закрытие дисков, зелёные тесты и линтеры.
