## ADDED Requirements

### Requirement: Видимый текст после установки режима BIOS
После установки текстового режима INT 10h AH=00h BIOS SHALL заполнять экран пробелами с атрибутом 07h, чтобы последующий teletype-вывод был видимым без дополнительной инициализации атрибутов гостем.

#### Scenario: Первый символ после mode 03h
- **WHEN** гость выполняет INT 10h AX=0003h и затем AX=0E41h
- **THEN** в первой клетке отображается A с атрибутом 07h, остальные клетки содержат пробелы с атрибутом 07h
