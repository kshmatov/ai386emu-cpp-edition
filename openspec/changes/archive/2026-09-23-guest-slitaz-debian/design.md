# Добавление SliTaz 4.0 Base и Debian 3.1 Sarge i386

> История Go-издания: упоминания Go-команд, путей и цифр ниже относятся к Go-реализации (ai386).

## Исходная задача и приёмка

Пользователь попросил добавить два дистрибутива из предложенного списка. Нужно обеспечить воспроизводимый запуск их официальных ISO в ai386, проверить реальные рубежи загрузки и записать результаты. Для SliTaz целевой рубеж — текстовая гостевая оболочка; для Debian — загрузка установщика, затем установка на HD и загрузка установленной системы, если эмулятор позволяет. Для обоих проверить доступную сеть. Неподтверждённые функции явно записать как ограничения.

## Подход

- ISO остаются в `/tmp` или задаются пользователем по флагу; в git входят только тесты и документы. Обычный пакет тестов пропускает тяжёлые ISO-прогоны без явного флага.
- Добавить отдельный диагностический тест для каждого гостя на основе `machine.New`, существующего VGA текстового снимка и PS/2 control-loop.
- Для каждого теста проверять SHA-256 локального ISO, запуск из CD, достижение измеримого гостевого рубежа. Дополнительные действия в ОС выполнять через ввод PS/2 и фиксировать в отчёте.
- Если найден дефект эмулятора, добавить регрессионный тест, исправить его и повторить гостевой прогон.

## Задачи и порядок

1. SliTaz: диагностический harness, запуск до оболочки, проверка сети и сохранение результата. Файлы: `internal/machine/*slitaz*test.go`, отчёт. Проверка: целевой тест с ISO; Done — реальный гостевой рубеж подтверждён.
2. Debian: диагностический harness, запуск установщика, по возможности установка и загрузка с HD, проверка сети. Файлы: `internal/machine/*debian*test.go`, отчёт. Проверка: целевой тест с ISO; Done — рубежи и ограничения подтверждены.
3. Интеграция: README, `go test ./...`, `go test -race ./...`, `go vet ./...`, `go build ./...`, `openspec validate --all --strict`, итоговый review против этого документа и AGENTS.md.

Задачи выполняются последовательно в текущем сеансе. Независимые тяжёлые гостевые запуски могут выполняться одновременно после готовности harness, если их диски разделены.
