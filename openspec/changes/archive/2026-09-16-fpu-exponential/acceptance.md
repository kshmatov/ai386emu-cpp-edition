# Приёмка F2XM1

> История Go-издания: упоминания Go-команд, путей и цифр ниже относятся к Go-реализации (ai386).

2026-09-11. D9 F0 регрессии сначала давали UD; после подключения инструкции проходят. 396 native x87 случаев: 33 аргумента от -1 до1, четыре RC, три PC; отклонение не более двух ULP. Данные `internal/cpu/testdata/f2xm1-native.txt` получены командой `cc reference.c -o /tmp/ai386-f2xm1-reference`, затем `/tmp/ai386-f2xm1-reference matrix`.

Отдельно проверены signed zero, аргумент2^-10000 без cancellation, минимальный extended subnormal обоих знаков со всеми RC, unmasked DE/UE/PE, пустой стек, SNaN/QNaN payload и unsupported encoding. Native вывод в reference.txt подтверждает вычисленный результат при unmasked PE и масштабирование на2^24576 при unmasked UE. Побитовое совпадение неопределённых C0/C2/C3 и всех физических моделей486 не заявляется.

Общие test/vet/build успешны, CPU6.265с, CPU race42.035с, дополнительные крайние случаи race1.131с; OpenSpec strict успешен. Остальные трансцендентные инструкции и общая полнота исключений FPU остаются открытыми в маршруте.
