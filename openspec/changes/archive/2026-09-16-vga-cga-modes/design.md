## Context
Матрица vga-mode-coverage подтверждает отказ BIOS для 04–06. Источники регистров: SeaBIOS rel-1.16.3 vgasrc/stdvgamodes.c; адресация odd/even: QEMU v8.2.2 hw/display/vga.c.

## Decisions
Определять способ рендера по регистрам окна, shift mode и CRTC, а не сохранённому номеру режима. В 04/05 использовать существующие плоскости с odd/even адресацией (plane = address bit0, offset = address/2); в 06 — плоскость 0 с обычной записью. При рендере адрес строки = (y/2)*80 + (y%2)*8192. Существующая логическая геометрия без удвоения scanline сохраняется, сравнение с QEMU проверяет каждый дублированный пиксель.

## Risks
Переключение из CGA должно сбрасывать odd/even и CRTC-режим; нужны регрессии перехода. RGB-расхождение преобразования DAC остаётся отдельно измеренным.
