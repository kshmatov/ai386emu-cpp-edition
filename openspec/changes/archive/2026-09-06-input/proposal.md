# Change Proposal: input

> История Go-издания: упоминания Go-команд, путей и цифр ниже относятся к Go-реализации (ai386).

## Why

Цель проекта — загрузить и «работать в» реальной ОС (Linux, FreeBSD). Без ввода это невозможно: гостевая ОС должна получать нажатия клавиш и события мыши стандартным способом — через контроллер PS/2 и прерывания (IRQ1/IRQ12). Сейчас эмулятор ввода не имеет: INT 16h — временная заглушка из этапа 4, контроллер прерываний и путь подачи событий с хоста отсутствуют.

## What Changes

- **Контроллер прерываний 8259** (эмуляция master+slave в каскаде): программируемые порты 0x20/0x21 (master) и 0xA0/0xA1 (slave), ICW/OCW, ремап векторов под гостевую ОС (Linux ставит IRQ1→0x21…), маскирование (OCW1), приоритет, EOI (OCW2), доставка вектора в CPU через существующий интерфейс `CPU.RequestInterrupt`.
- **Контроллер PS/2 (8042)**: порты 0x60/0x64, буфер вывода со статус-байтом, байт команды контроллера, перевод скан-кодов (translation), команды тестирования и D4 (переключение на мышиный порт) — достаточный объём для инициализации драйвером гостевой ОС.
- **Клавиатура PS/2**: скан-коды набора 1, события нажатия/отпускания (make/break), залипающие модификаторы.
- **Мышь PS/2**: потоковые пакеты движения (приращение координат по осям) и кнопок.
- **Программный API ввода машины**: публичный интерфейс подачи событий клавиатуры и мыши, через который события попадают в контроллер PS/2; источник — тесты и будущий внешний фронтенд (этап UI отдельный, в роадмапу не входит).
- **INT 16h (BIOS)**: замена синтетической заглушки на чтение реального буфера скан-кодов устройства.

## Capabilities

### New Capabilities
- `input`: ввод клавиатуры и мыши с хоста в гостевую ОС — программный API подачи событий, контроллер PS/2 и клавиатура/мышь (скан-коды set 1, make/break, модификаторы, PS/2-пакеты движения и кнопок), прерывания ввода через контроллер 8259 (IRQ1 — клавиатура, IRQ12 — мышь, ремап векторов, маскирование, EOI).

### Modified Capabilities
- `bios`: требование «Заглушки видео и клавиатуры BIOS (INT 10h, INT 16h)» — INT 16h перестаёт быть заглушкой: проверка/чтение клавиши выполняются через реальный буфер скан-кодов устройства ввода. Внешнее поведение AH=00h/01h меняется с «синтетической клавиши» на «данные реальной клавиатуры».

## Impact

- Новые пакеты: `internal/pic` (контроллер 8259), `internal/ps2` (контроллер 8042 + клавиатура + мышь), API ввода (подача событий) на уровне `internal/machine`.
- `internal/cpu`: изменений не требуется — интерфейс аппаратных прерываний (`RequestInterrupt`) реализован на этапе 4.
- `internal/bios`: переписывается обработчик INT 16h (AH=00h/01h, состояние модификаторов).
- `internal/machine`: добавление устройств на шину, связывание IRQ1/IRQ12 с PIC, доступ к подаче событий ввода.
- Тесты: юнит для PIC (ICW/OCW, EOI, маскирование, каскад, приоритет), юнит для контроллера PS/2 (команды, статус, перевод скан-кодов), юнит для API подачи событий; e2e: гостевая ОС через обработчик прерывания получает скан-код и пакет мыши, e2e INT 16h.
- Не затрагиваются: VGA, хранение, конфигурация, CLI.

### Non-goals
- Реальный аппаратный ввод с клавиатуры/мыши хоста (без GUI-фронтенда) — только программный API подачи событий.
- Наборы скан-кодов 3 и переключение наборов ПО; поддержка только набора 1 с опциональным переводом контроллером.
- APIC/ACPI (архитектура i486 — только 8259), joystick, сенсорный ввод.
- DMA/звук — предмет этапа SoundBlaster16.
