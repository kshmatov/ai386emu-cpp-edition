## 1. Контроллер прерываний 8259 (`internal/pic`)

- [x] 1.1 Эмуляция микросхемы 8259: программируемые ICW1–ICW4 (база векторов ICW2, каскад ICW3, режимы ICW4), OCW1 (маска), OCW2 (EOI специфичный/неспецифичный, ROI), OCW3 (чтение ISR/IRR), состояние IRR/ISR, разрешающая логика приоритета линии.
- [x] 1.2 Две микросхемы master+slave в каскаде (slave на master-IRQ2): регистрация портов 0x20/0x21 и 0xA0/0xA1 на шине, интерфейс линий `RaiseIRQ(level)`/`LowerIRQ(level)`, доставка вектора в CPU через `cpu.RequestInterrupt(base+level)` при решении «доставить», повторная доставка после EOI при активном условии линии.
- [x] 1.3 Юнит-тесты `internal/pic`: последовательности ICW/OCW (ремап базы IRQ1→0x21 и IRQ12→0x2C), маскирование, неспецифичный/специфичный EOI, приоритет (IRQ0>IRQ1>IRQ12, каскад), чтение IRR/ISR, сценарий повторной доставки без/g с EOI.

## 2. Контроллер PS/2 (8042) и клавиатура (`internal/ps2`)

- [x] 2.1 Контроллер 8042: порты 0x60/0x64, буфер вывода, статус-байт (output/input buffer full, самотест, бит данных мыши), кэш байта команды, команды порта 0x64 (0x20/0x60/0xAA/0xA7/0xA8/0xA9/0xAB/0xD4/0xFE), ACK на приём байтов, режим перевода скан-кодов.
- [x] 2.2 Клавиатура PS/2 набор 1: make/break-скан-коды (включая E0-клавиши), залипающие (Shift/Ctrl/Alt) и переключающие (Caps/Num/Scroll) модификаторы, генерация IRQ1 при выводе байта в буфер.
- [x] 2.3 Юнит-тесты `internal/ps2`: чтение буфера/статуса, каждая реализованная команда, ACK, перевод скан-кодов, make/break клавиатуры, поднятие линии IRQ1, состояние модификаторов.

## 3. Мышь PS/2 (`internal/ps2`)

- [x] 3.1 Мышиный порт через 0xD4: команды мыши (0xFF сброс, 0xF4 enable, 0xF6/0xF7 disable, 0xE8 разрешение), режим потоковой выдачи, пакет из 3 байт (кнопки, знаки, переполнение, приращения dx/dy), статусное различие данных мыши (bit5), генерация IRQ12 через slave-порт.
- [x] 3.2 Юнит-тесты мыши: enable и поток данных, движение (приращения и переполнения 8-битные), кнопки, различение мышиных/клавиатурных данных, доставка через каскад на master.

## 4. Программный API подачи ввода и машина

- [x] 4.1 В `internal/ps2`: выходная очередь байтов (с признаком «мышиные данные») с выдачей по одному через буфер вывода, очередь событий нажатий клавиатуры для INT 16h, генерация EDGE-сигнала IRQ при «буфер из пустого → непустой».
- [x] 4.2 Публичный доступ `machine.Input()` с методами `KeyEvent(scancode, pressed)` и `MouseEvent(dx, dy, buttons)`, связывание событий с портами PS/2 и линиями IRQ1/IRQ12 через PIC в `internal/machine`.
- [x] 4.3 Юнит-тесты `internal/ps2` и `internal/machine`: приём событий API, поток данных драйверу через 0x60, очередь нажатий для BIOS, поднятие соответствующих IRQ-линий.

## 5. BIOS: реальные сервисы INT 16h (`internal/bios`)

- [x] 5.1 INT 16h AH=01h (проверка без извлечения: ZF по пустоте буфера), AH=00h (блокирующее извлечение кода из буфера), AH=02h (состояние модификаторов) на основе устройства ввода; замена синтетической заглушки.
- [x] 5.2 Юнит-тесты `internal/bios`: заново INT 16h сценарии (пустой/непустой буфер, извлечение, залипшие модификаторы), регрессия INT 10h сценариев.

## 6. e2e и приёмка

- [x] 6.1 e2e `internal/machine`: гостевой загрузочный код программирует PIC (база векторов), ставит обработчики IVT на векторы IRQ1/IRQ12, открывает IF; передача клавиши и мыши через `machine.Input()`; проверка, что обработчики прочитали скан-код/пакет из порта 0x60 и записали маркер в память.
- [x] 6.2 e2e INT 16h: гостевой код в реальном режиме использует AH=01h/00h с реальной клавиатурой через API ввода.
