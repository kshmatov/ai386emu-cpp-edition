## Context

CPU хранил один ожидающий вектор, а PIC помечал IRQ обслуживаемым до его приёма. См. proposal.md.

## Decisions

CPU вызывает подтверждение контроллера между инструкциями при IF=1. PIC выбирает кандидата и меняет IRR/ISR в момент подтверждения. Machine использует этот путь; прежний callback PIC остаётся для клиентов с немедленным подтверждением. Подключение сохраняется при reset CPU как часть аппаратной проводки.

Очередь векторов CPU не выбрана: она зафиксировала бы приоритет и маски раньше реального подтверждения.

Источник: [Intel 8259A, Interrupt Sequence](https://www.cs.umb.edu/cs341/Intel8259/I8259APIC.pdf), перенос IRR→ISR по INTA.

## Risks / Trade-offs

Все проверки выполняются в однопоточном цикле VM. Полные специальные режимы 8259 не входят в изменение.
