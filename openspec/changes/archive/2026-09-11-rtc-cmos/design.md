## Context

См. proposal.md. PIT уже получает виртуальные такты из Machine.Step; CPU принимает IRQ через PIC.Acknowledge.

## Decisions

Новый internal/rtc хранит CMOS и фазу генератора 32768 Гц. Advance работает событийно, без goroutine и ожидания времени хоста. Machine отдельно преобразует циклы CPU и idle HLT в такты RTC с сохранением дробной части. Callback фронта IRQ8 подключён к существующему PIC.

Начальное значение `host` берётся один раз при создании VM, фиксированное RFC3339 задаётся через конфигурацию. После создания VM wall clock не используется. Это сохраняет воспроизводимость и согласованность с PIT.

CMOS содержит BCD 24h по умолчанию, век 32h, память 15h/16h, 17h/18h и 30h/31h, память выше 16 МиБ в 34h/35h, тип floppy 10h и equipment 14h. Пользовательская запись календаря через SET сохраняется; C/D read-only. Выключение делителя останавливает обновления; после снятия reset первый update через 500 мс.

Источники: [DS12887 datasheet](https://www.analog.com/media/en/technical-documentation/data-sheets/DS12885-DS12C887A.pdf), [QEMU PC CMOS layout](https://github.com/qemu/qemu/blob/master/hw/i386/pc.c). Реализация собственная.

## Risks / Trade-offs

DST, батарейное сохранение между процессами, NMI-источники и BIOS INT1A вне текущего блока. Маска NMI хранится без генерации NMI. Приёмка не заявляет точного совпадения электрических таймингов обновления или полной реализации всех вариантов RTC.

Полный DSL-прогон дорогой; обязательны сначала модульные/интеграционные тесты, затем проверка загрузки и даты гостя.
