# Исправление установки FreeDOS

Задача пользователя: устранить ошибку установки FreeDOS на HD.
Критерии: исходная `.Error!` исчезает, установщик запускается; проверить путь установки на отдельном HD и последующую загрузку; регрессии покрыты тестами, линтеры и сборка проходят.

Решения, подтверждённые воспроизведением:
- BIOS dispatch учитывает замену IVT гостем; оригинальные ROM entry сохраняют native services для chaining.
- ROM thunk обновляет сохранённые FLAGS с результатом сервиса и возвращается IRET, сохраняя IF/TF.
- INT12 читает актуальную BDA conventional memory, сохраняя резервирование MEMDISK.
- Эмуляция CPU не меняется до воспроизведения точной инструкции/условий оставшегося сбоя.

Задачи:
1. BIOS vectors + BDA: владелец root; файлы internal/bios; тесты BIOS regression. Выполнено.
2. Гостевая приёмка и оставшийся сбой: root; зависимость 1; диагностический прогон на /tmp HD, затем точная регрессия при подтверждённом дефекте.
3. Независимая проверка BIOS: review agent; зависит от 1; проверить native/far-call/guest chaining и FLAGS. Не должно остаться высоких замечаний.
4. Интеграция: root; зависит от 2/3; make check, Windows builds, фактический установщик, документация результата.
