# Комплект установки FreeDOS 1.4

Исходная задача: подготовить образ для загрузки и установки DOS 6.22 или аналогичной системы.

## Критерии приёмки

1. Используется свободно распространяемый DOS-совместимый дистрибутив из официального источника.
2. Архив проверен по опубликованной SHA-256 сумме.
3. Подготовлены загрузочный ISO и отдельный пустой raw-HD, не затрагивающие существующий `vm.img`.
4. Есть готовая конфигурация ai386 и понятная команда запуска.
5. Загрузочность ISO проверена хотя бы независимым эталонным эмулятором; по возможности — ai386.

## Решение

- Дистрибутив: FreeDOS 1.4 LiveCD.
- Носитель установки: `FD14LIVE.iso`, извлечённый из официального ZIP.
- Целевой диск: sparse raw `freedos.img`, 256 МиБ.
- Конфигурация: `freedos-install.toml`, сначала CD, затем HD; 32 МиБ RAM; оконный frontend.

## Проверки

- SHA-256 ZIP и состав архива.
- Размер и MBR-нулевое начальное состояние raw-HD.
- El Torito boot catalog ISO.
- Загрузка в QEMU до меню/гостевого выполнения.
- Сборка и короткий диагностический запуск ai386.

## Граф задач

1. Получить и проверить архив — владелец: основной агент.
2. Извлечь ISO и создать HD/config — зависит от 1; владелец: основной агент.
3. Проверить носители и загрузку — зависит от 2; владелец: основной агент.
4. Review gate — зависит от 3; владелец: основной агент.
