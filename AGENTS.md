# Цель проекта
Создание работающего эмулятора компьютера i486DX4-100
Экран - VGA с поддержкой всех текстовых и графических режимов
Звуковая карта - SoundBlaster16
Для HD диска используется реальный файл, он создается при создании ВМ, так же может быть указан один или несколько путей файловой системы для эмуляции CD диска.
Мышь, клавиатура.
Сеть - реальная сеть компьютера.

Эмулятор должен подерживать параметры командной строки для указания пути для создания/использования HD и для подключения как CD, для указния объема RAM и для указания очередности загрузки.
Так же параметры могут записываться в файл конфигурации, который может быть передан эмулятору при запуске. 

Эмулятор должен быть в состоянии загружать операционную систему с созданого диска (Linux, FreeBSD) и позворять работать в ней.

## Стек
- C++ стандарт 2020, сборка — CMake (vcpkg)
- тесты — GoogleTest (ctest), линт — clang-tidy, форматирование — clang-format

## Тулинг и команды
- сборка: `cmake -S . -B build && cmake --build build`
- тесты: `ctest --test-dir build --output-on-failure`
- линт: `clang-tidy` по compile_commands.json из CMake
- форматирование: `clang-format -i`
- спеки: `openspec validate --all --strict`


## Общие правила
- язык общения русский, документация и комментарии на английском.
- не гадай и не предполагай, если что-то неясно из этого файла и спецификаций, то спрашивай
- пиши простой человекочитаемый код с соблюдением общепринятых практик
- тесты обязательны
- работа ведется в ветках по git-flow
- цикл разработки обязательно должен проходить через шаги - кодирование, тесты, линтеры, исправление если надо, приемка
- если какие-то параметры разумно делать настраиваемыми, то они хранятся в файле конфигурации
