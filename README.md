# ai386emu-cpp-edition

Повтор эмулятора для i486dx4-100 на языке C++ по уже существующей спецификации из проекта на Go. Название ai386 - это название первоначального проекта, оставил как зонтичное наименование. 
Проект сделан для сравнения возможностей AI в разработке на разных языках. В дальнейшем еще планирую аналогичные проекты на C, Rust и Zig

Разработка по SDD методологии с использованием openspec

Человек в проекте участвует только как менеджер проекта: постановка задач, уточнение спецификаций и т.п.
